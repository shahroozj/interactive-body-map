Interactive Body Map

A clickable human body diagram in plain HTML, CSS and JavaScript. Every region links to any URL you choose. Scalable vector artwork on a transparent background, so it sits on your page rather than on a box.

No dependencies 5.7 KB gzipped Desktop & touch Keyboard accessible Real <a> links

Live demo

Hover, tap or tab through the figure. Both diagrams below are the same component in two different modes.

Simple mode — 9 regions

Head, neck, chest, abdomen, pelvis, both arms, both legs.

Detailed mode — 21 regions

Limbs split into shoulder, upper arm, forearm, hand — thigh, knee, lower leg, foot.

Themed & selectable

Click a region.

Quickest possible install

Three lines. No JavaScript to write — the links live in HTML attributes.

<!-- 1. the stylesheet, in <head> -->
<link rel="stylesheet" href="css/body-map.css">

<!-- 2. the diagram, anywhere in the page -->
<div data-body-map
     data-part-head="/conditions/head"
     data-part-chest="/conditions/chest"
     data-part-abdomen="/conditions/abdomen"
     data-part-arm-left="/conditions/arms"
     data-part-arm-right="/conditions/arms"
     data-part-leg-left="/conditions/legs"
     data-part-leg-right="/conditions/legs"></div>

<!-- 3. the script, before </body> -->
<script src="js/body-map.min.js"></script>

Elements carrying data-body-map start themselves on page load. Nothing else is required.

Configuring from JavaScript

For anything the attributes cannot express — callbacks, per-region colours, dynamic links.

<div id="body-map"></div>

<script>
BodyMap.init('#body-map', {
  mode: 'detailed',
  target: '_blank',
  parts: {
    head:      '/anatomy/head',
    chest:     { url: '/anatomy/chest', label: 'Chest & ribs' },
    // one key covers both sides and every segment inside them
    arms:      '/anatomy/arms',
    legs:      '/anatomy/legs',
    // a more specific key always wins
    'hand-left':  { url: '/anatomy/hands', color: '#f59e0b' },
    'hand-right': { url: '/anatomy/hands', color: '#f59e0b' },
    pelvis:    false   // drawn, but not clickable
  },
  theme: { fill: '#b8c4d0', hover: '#0ea5e9' },
  onSelect: function (part, event) {
    console.log(part.id, part.label, part.url);
    // return false to stay on the page
  }
});
</script>

Group keys

Setting a group key links everything inside it at once, so you rarely need all 21 entries: arms, legs, hands, feet, knees, thighs, shoulders, forearms, upper-arms, lower-legs, plus arm-left, arm-right, leg-left and leg-right in detailed mode.

Methods

BodyMap.init(target, options)Create. target is a selector, element or list.
BodyMap.get(target)Instance already attached to an element.
BodyMap.parts(mode)Array of region metadata.
instance.setParts({…})Merge in new links and redraw.
instance.setOptions({…})Merge in new options and redraw.
instance.select(id) / .clear()Highlight a region.
instance.destroy()Remove everything and unbind.

Styling

Colours are CSS custom properties. Override them wherever you like — no need to edit the plugin stylesheet.

/* every diagram on the site */
.bodymap {
  --bodymap-fill: #cbd5e1;
  --bodymap-fill-hover: #0ea5e9;
  --bodymap-fill-active: #0369a1;
  --bodymap-stroke: #64748b;
  --bodymap-detail: #64748b;
  --bodymap-tooltip-bg: #0f172a;
  max-width: 340px;
}

/* one region only */
.bodymap__region[data-bodymap-part="head"] {
  --bodymap-fill-hover: #f59e0b;
}

/* outline style */
<div data-body-map class="bodymap--outline"></div>

The stylesheet already answers prefers-color-scheme: dark and prefers-reduced-motion. Add data-bodymap-theme="light" to opt a diagram out of the dark palette.

Notes on the details

  • Transparent. Neither the container nor the SVG paints a background, so the figure blends into any page colour or image.
  • Real links. Each region is an SVG <a href>: crawlable, middle-clickable, and it shows the URL in the status bar.
  • Responsive. The artwork is vector and scales with its container. Set max-width and nothing else.
  • Touch. Hover effects are gated behind @media (hover: hover), so tapping never leaves a region stuck in the hover colour.
  • Keyboard. Tab moves between regions in anatomical order, Enter follows the link, and the focused region is outlined along the body edge.
  • Size. One JS file and one CSS file: 5.7 KB and 1.2 KB gzipped. No fonts, no images, no network requests.
